# 成果報告規格（KNN、區別分析、單純貝氏、支援向量機）

## 交付物與讀者

- 交付 `report.html`（主要報告）、`report.md` 與 `report.qmd`；`report.pdf` 只在使用者需要（config 的 `pdf` 設為 `"on"`）且環境可行時才有。皆來自同一內容結構，數值、圖表與結論必須一致；每份報告最後都附完整 Python 程式碼（`report.html` 與 `report.qmd` 中的程式碼預設收合，`report.qmd` 的程式碼不執行）。
- 讀者同時包含統計背景與非統計背景（諮詢者）。正文使用精準的統計術語，**術語本身不另外解釋**；但每個結果都要附給諮詢者的解讀，說明這個結果代表什麼結論，例如「p = 0.012 < 0.05，表示兩個模型的錯誤率差異不太可能只是隨機造成，LDA 確實比 KNN 少錯」、「資料可分為 3 類，分別是……」、「精確率 0.62：被判為違約的客戶中約六成真的違約」。
- 報告內所有數值與圖表都必須來自實際執行的 Python 程式輸出，不得由 AI 自行估算、改寫數字或繪製示意圖（見「重現合約」）。

## 版面與字型

- **中文優先標楷體，英文與數字優先 Times New Roman**，以字型清單指定（英文字型在前、中文楷體在後）；系統沒有時由瀏覽器自動改用相近字型，因此不得宣稱一定使用了指定字型。數學式以 LaTeX 語法撰寫。
- 圖表字型在程式開頭統一設定為清單，只保留系統實際有的字型，例如 matplotlib：

```python
import matplotlib.pyplot as plt
plt.rcParams["font.family"] = ["Times New Roman", "DFKai-SB", "Microsoft JhengHei"]   # 只列系統有的字型
plt.rcParams["axes.unicode_minus"] = False
```

  系統一個中文字型都沒有時，在附錄警告「圖中的中文可能顯示為方框」。
- 白底、深色標題；配色使用色盲友善的淺色系，同一類別在所有圖中使用相同顏色。
- 數字格式：比例以百分比呈現到小數第一位；準確率、AUC 等指標到小數第三位；筆數加千分位。

## 必要章節與順序

### 1. 研究問題

- 背景、觀測單位（一列代表什麼）、反應變數 Y 與解釋變數 X、分析目的（分類預測、找出區分各類的變數、迴歸預測）。
- Y 為類別時列出各類別的意義；二元時標明**正類**（例如「違約 = 1」）。
- 未知的背景、來源、單位明確標示「未提供」，不自行補寫。

### 2. 重點結果與建議

- 3–5 點，先直接回答研究問題。
- 必須包含：最終採用的方法與理由（一句話）、測試集上的主要指標與**基準模型**的比較、最常見的錯誤型態（例如「實際違約者有 41% 被判為不違約」）、建議及其適用前提。
- 未提供誤判成本或可接受誤差時，不宣稱模型可直接上線使用。

### 3. 資料與方法

**3.1 樣本與變數**：原始筆數與變數數、Y 的各類別筆數與比例、最終進入模型的筆數與變數數。

**3.2 缺失與處理**：以表格列出每個變數的缺失筆數、缺失比例、實際採用的處理方式、實際處理筆數，並列出處理前後的樣本數與變數數。

| 變數 | 型態 | 缺失筆數 | 缺失比例 | 處理方式 | 處理筆數 | 插補值／刪除理由 |
|:--|:--|--:|--:|:--|--:|:--|

- 數值型 X 缺失比例 ≤ 20% 時預設建議中位數插補；> 20% 時經使用者確認後才刪除變數，並記錄確認內容。
- 類別型 X 與缺失的 Y 另列處理方式，不套用數值型 X 的規則。
- 說明 KNN、LDA、QDA、SVM 都不接受缺失值，因此必須先處理。

**3.3 前處理**：標準化、類別編碼、文字轉詞頻等每一步的做法與理由。KNN 與 SVM 必須標準化（理由：兩者以距離運作，未標準化時單位大的變數會主導結果）；所有前處理放在 `Pipeline` 中，只用訓練資料估計參數。

**3.4 模型選用理由**：先以統計診斷表列出判斷依據、本資料的實際數值與對應的門檻（依 `decision-tree.md`，每列標明「建議依據」或「可行性條件」），再以三張表列出方法：**建議方法**（附理由）、**其他可行方法**（附說明）、**不可行方法**（附原因）；最後列出使用者最後確認的候選方法（含加選的其他可行方法）與自動加入的比較基準。

| 性質 | 判斷依據 | 本資料的數值 | 依據的規則 | 對方法選擇的影響 |
|:--|:--|:--|:--|:--|
| 建議依據 | Y 型態 | 例：二元（違約／不違約） | Y 為類別 → 分類方法 | |
| 建議依據 | 樣本數 $n$、原始變數數、進入模型的欄位數 $p$、$n/p$ | 例：$n$ 為訓練資料筆數，$p$ 為編碼後的欄位數 | $n/p < 10$ → p 接近 n，建議收縮 LDA、線性核 SVM | |
| 建議依據 | 每折最小類別筆數與 $10p$ | | ≥ $10p$ → 每類樣本數遠大於 p，建議 QDA、RBF 核 SVM | |
| 建議依據 | KNN 適用 | | $p \le 10$ 且 $n/p \ge 20$ → 建議 KNN | |
| 建議依據 | 類別比例 | 例：違約僅 3.3% | 稀有類別 → 調門檻、看敏感度／精確率 | |
| 建議依據 | 特徵型態 | 連續、類別、計數 | 類別型占一半以上 → 建議單純貝氏（連續＋類別）；文字 → 多項單純貝氏、線性核 SVM | |
| 建議依據 | 特徵間最大相關 | | ≥ 0.7 → 不建議單純貝氏 | |
| 建議依據（參考） | 各類散佈 | 各類標準差比、相關差異 | 只當參考 | |
| 可行性條件 | 每折最小類別筆數與 $p$ | | ≤ $p$ → QDA 不可行 | |
| 可行性條件 | $p$ 與 $n$ | | $p \ge n$ → LDA 不可行 | |
| 可行性條件 | 樣本規模 | 訓練資料 $n$ | $n > 20{,}000$ → 核 SVM、SVR 不可行 | |

| 建議方法 | 理由 |
|:--|:--|

| 其他可行方法 | 說明 |
|:--|:--|

| 不可行方法 | 原因 |
|:--|:--|

每一列都要附對結論的解讀，例如「每個變數平均有 5,000 筆資料，資料量相對變數數充足，因此可以考慮彈性較高的方法」。邊界形狀（線性是否足夠）不在此判斷，改在第 5 章模型比較時解讀。

**3.5 資料切分**：訓練／測試比例、是否分層抽樣（`stratify=y`）、隨機種子；時間或排序資料的切分方式。說明測試集只在最後使用一次。

**3.6 交叉驗證與參數搜尋**：折數、評估指標（不平衡資料不用準確率選模）、各方法的參數網格與最終選出的參數，並註明最佳值是否落在網格邊緣。

| 方法 | 調整參數 | 搜尋範圍 | 選出的值 | CV 指標（平均 ± 標準差） |
|:--|:--|:--|:--|:--|

### 4. EDA 探索性資料分析

呈現前處理後、判斷 Y 類型及模型推薦**之前**執行的探索結果：

- 描述統計（整體，以及 Y 為類別時依類別分組）。
- 前處理前後的缺失概況。
- Y 的類別次數圖（標示各類筆數與比例）。
- 適用數值變數的直方圖與箱形圖；Y 為類別時，箱形圖依類別分組。
- 依資料類型補充：類別變數的次數圖（依 Y 分組的比例）、散佈圖（依類別上色）、相關性熱圖。
- $p$ 很大時（例如超過 20 個），正文只呈現依明確規則挑出的變數（例如兩類平均差最大的前 10 個），並說明挑選規則，其餘放附錄。

每張圖都要有白話解讀，說明分佈、偏態、可能的離群點與變數之間的關係，以及**對後續模型推薦的意義**（例如「兩類的箱形圖幾乎重疊，單一變數難以區分兩類」、「兩類的散布形狀相近，支持 LDA 的共同共變異假設」）。離群點只標示與說明，不自動刪除。不適用的圖表說明原因。會影響選模的 EDA 以訓練資料為依據。

### 5. 模型結果與診斷

- **模型比較表**：所有候選方法與基準模型的 CV 指標（平均 ± 標準差）與測試集指標；明確區分訓練、交叉驗證與測試的結果。無法估計而略過的方法列出原因。
- **邊界形狀**：依比較結果解讀，例如線性方法與 KNN、RBF 核 SVM 表現相近時，線性邊界已足夠；彈性高的方法明顯較好時，邊界不規則。
- **分類指標**：準確率、錯誤率、敏感度（召回率）、特異度、精確率、F1；不平衡資料加上平衡準確率與 AUC；多類別時列出各類別的指標。每個指標都要解讀其數值對研究問題的意義，例如「敏感度 0.59：實際違約的客戶中，模型抓到約六成，仍有四成會被漏掉」。
- **混淆矩陣**：列為實際類別、欄為預測類別，標明正類與 0／1 對應，並解讀主要的錯誤型態。
- 二元且有機率輸出時附 ROC 曲線；不平衡資料附不同門檻下的敏感度、精確率與整體錯誤率表，說明最後採用的門檻與理由。
- **方法特定診斷**：

| 方法 | 必附的診斷 |
|:--|:--|
| KNN | CV 誤差對 $k$ 的曲線，標出選出的 $k$ |
| LDA | 區別座標散佈圖（依類別上色）、各區別方向承載的組間變異比例 |
| QDA | 各類共變異結構的比較；若任一類 $N_k$ 接近 $p$，說明估計的不穩定 |
| 單純貝氏 | 使用機率時附校準檢查（預測機率分組 vs. 實際比例） |
| SVM | $(C, \gamma)$ 的 CV 曲面圖並標出最佳點；支援向量個數 |
| SVR、KNN 迴歸 | 預測值對實際值圖、殘差圖；RMSE、MAE、$R^2$，並與「以平均數預測」的基準比較 |

- **統計推論**：p 值、信賴區間可以呈現，但一律附結論性解讀，寫出檢定的虛無假設、使用的顯著水準與結論。例如測試集準確率附 95% 信賴區間（「0.82–0.90，表示在類似的新資料上，準確率大約落在這個範圍」）；比較兩個模型在同一測試集上的表現時，可用 McNemar 檢定（「p = 0.012 < 0.05，兩個模型的錯誤率差異達統計顯著，代表 LDA 確實比 KNN 少錯，不只是測試集的隨機波動」）。「顯著」只用於有實際檢定的情況，並說明其意義；「不顯著」須寫成「沒有足夠證據顯示有差異」，不寫成「沒有差異」。
- KNN 與 RBF 核 SVM 沒有係數可解釋，若要說明變數的重要性，只能用測試集上的排列重要性（permutation importance），並說明它代表「對預測的貢獻」，不是因果效果。

### 6. 限制

- 遺漏變數、樣本代表性、模型形式的假設（例如單純貝氏的獨立假設、LDA 的共同共變異）。
- 測試集筆數不多時，測試指標本身有不小的波動（以信賴區間呈現）。
- 類別不平衡、門檻選擇與誤判成本未知的影響。
- 若有缺失或插補，說明缺失機制的不確定性，以及插補可能改變分佈、變異與變數關係。
- 未檢查的事項與適用邊界（例如資料分佈改變時模型可能失效）；不作因果宣稱。

### 7. 附錄

- 本次使用方法的公式與技術細節（區別函數、核函數、損失函數等，只放實際使用的方法）。
- 完整的 CV 結果表、正文未呈現的 EDA 圖與診斷圖。
- 套件版本、Python 版本、實際使用的字型、隨機種子、資料檔 SHA-256 雜湊值與重現指令。
- 精簡可靠的參考來源。

### 8. 完整 Python 程式碼

放在最後，列出每個檔名與全部程式內容；不得以「其餘省略」或未提供的自訂工具代替。必須包含本次實際使用的缺失計算、插補、經確認的變數刪除、EDA 描述統計與全部 EDA 圖表、模型配適、交叉驗證、測試集評估與全部診斷圖的程式。

## 寫作規範

- 術語不另外解釋，但每個表格、圖與數值之後都要有一到三句給諮詢者的解讀，說明它回答了研究問題的哪一部分、得到什麼結論。
- 方法選擇與每個結論都要寫出依據（樣本數、維度、類別比例、EDA 的觀察或 CV 結果），不只寫結論。
- 正文的每個數字都要能在程式輸出的表格或圖中找到；四捨五入規則全文一致。
- 不將關聯或預測表現當成因果證據。

## 重現合約

- **所有數值與圖表必須由實際執行的 Python 程式產生**：圖檔由程式以 `savefig` 輸出後嵌入報告，圖說註明產生該圖的檔名與函式；不得由 AI 直接繪製、描述或修改圖表內容。
- 程式將報告用到的關鍵數值（樣本數、缺失處理筆數、選出的參數、CV 與測試指標、混淆矩陣）寫入 `results.json`；報告中的數字從此檔取得，交付前比對報告數字與 `results.json` 一致。
- 資料經檔案路徑匯入；程式開頭集中設定資料路徑、Y／X、正類、輸出位置、隨機種子，以及使用者已同意的前處理方案（插補方式、刪除的變數）。
- 只需一個入口命令即可重現全部數值與圖表；允許多個同目錄模組，但必須全部附在報告末尾。
- 前處理（插補、標準化、編碼）放在 `Pipeline` 中，只以訓練資料估計參數，交叉驗證每一折重新估計；未採用的程序不得在重跑時自動啟用。
- 隨機種子固定；附實際套件版本與安裝、執行指令；原始資料不必內嵌，但需記錄雜湊值。
- 程式遇路徑或欄位錯誤即停止；依賴缺少、無法估計或未收斂時明確報錯，不得只產出部分檔案就宣稱完成。
- 交付前重新執行一次完整程式，確認輸出與報告一致；浮點、字型與平台差異須註明。
